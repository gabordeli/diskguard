# Contributing

This GitHub repository is a **one-way, read-only mirror** of the private GitLab
development repository. Development happens on GitLab; GitHub only mirrors the
`main` branch, tags and releases.

- **Do not commit** to the GitHub repository; the next mirror sync may overwrite
  your changes.
- **Issues/PRs:** not the primary channel. If you open one, the maintainer may
  port it to GitLab manually; PRs are not merged directly.
- **Releases:** `vX.Y.Z` tags come from the GitLab release job; GitHub Actions
  builds the GitHub Release after the tag.
- **Source:** the private GitLab repository; GitHub is only a mirror.
